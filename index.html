                  ExpenseFlow – Smart Personal Expense Tracker

                  A personal finance dashboard built with HTML, CSS and vanilla JavaScript for a 3-member group activity covering JavaScript Weeks 1–5.

                  • CourseJavaScript Weeks 1–5 – Group Activity
                  • MembersMember 1 · Member 2 · Member 3
                  • StackHTML5 · CSS3 · Vanilla JS · localStorage · Chart.js

                  Factory Pattern

                  TransactionFactory.createTransaction(data) builds every new transaction object with a generated id, normalized amount and timestamp. Used when adding, duplicating or generating recurring transactions.

                  Singleton Pattern

                  ExpenseTracker.getInstance() returns one central manager that owns transactions, budgets, categories, recurring items and all calculations — only one instance exists for the whole app.

                  Strategy Pattern

                  applySortStrategy(name, list) switches between sorting strategies (newest, oldest, highest, lowest, A–Z, Z–A) at runtime without changing the calling code.

                  Expected User Flow

                  1. Open ExpenseFlow
                  2. View dashboard
                  3. Add transaction
                  4. Factory creates the transaction object
                  5. Singleton manager stores it
                  6. Transaction pushed into the array
                  7. localStorage saves the data
                  8. Dashboard recalculates totals
                  9. Bento cards, analytics and budgets update
