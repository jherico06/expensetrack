# UI/UX Pro Max Rules & Icon Guidelines

## 1. Mandatory UI/UX Standards
* Always follow the guidelines defined in the `ui-ux-pro-max` skill whenever designing, modifying, or reviewing user interfaces, components, color systems, spacing, and animations.
* Maintain visual hierarchy, consistent 8px grid spacing, high-contrast dark/light mode states, and WCAG AA accessibility (4.5:1 minimum contrast for text).

## 2. Professional Icons (No Emojis)
* **Never use emojis as icons or badges** in the interface (e.g. avoid 🍔, 🚗, 💼, 📚). Emojis render inconsistently across Windows, macOS, Android, and iOS, breaking the premium fintech aesthetic.
* **Always use Lucide SVG icons** for all categories, navigation items, metrics, and actions.
* Icons must use consistent stroke widths (`stroke-width="2"`), rounded caps/joins (`stroke-linecap="round"` `stroke-linejoin="round"`), and scale proportionally with text.
